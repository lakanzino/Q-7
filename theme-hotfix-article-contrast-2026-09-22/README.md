# اصلاح کنتراست بخش‌های سفید مقاله

## علت

فایل `qpedia-layouts.css` برای سه جزء پس‌زمینه ثابت سفید (`#fff`) تعریف می‌کرد، درحالی‌که تم Cosmic در `custom.css` رنگ متن را روشن تنظیم می‌کند. اصلاح قدیمی فهرست مطالب نیز selector اشتباه `.qp-article__toc` داشت؛ کلاس واقعی `.qp-article-toc` است.

## فایل جایگزین

فقط این فایل باید جایگزین شود:

```text
wp-content/themes/quantum-pedia-child/assets/css/custom.css
```

## بخش‌های اصلاح‌شده

- برچسب دسته مقاله: `.qp-article__chip`
- فهرست مطالب: `.qp-article-toc`
- کادر مقاله قبلی و بعدی: `.post-navigation .nav-previous` و `.post-navigation .nav-next`
- تیتر اصلی مقاله: `.qp-article__title`

رنگ پس‌زمینه کادرها با کارت تیره قالب هماهنگ شده و متن و لینک‌ها روشن و خوانا هستند. تیتر اصلی مقاله نیز به آبی روشن `#3BA7F2` تغییر کرده است. هیچ PHP، JavaScript، قالب صفحه یا بخش دیگری تغییر نکرده است.

## پس از جایگزینی

کش افزونه کش، CDN و مرورگر را پاک کنید. چون قالب فایل CSS را با `filemtime()` نسخه‌گذاری می‌کند، پس از جایگزینی فایل باید URL نسخه جدید تولید شود.
