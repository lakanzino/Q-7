## راستی‌آزمایی لینک‌ها (مهم‌ترین بخش)

هیچ اسلاگی از ذهن نوشته نشد. هر ۱۸۵ مقصد در همین نشست با REST زنده چک شد — چون فهرست ۱۰تاییِ پیش‌فرض REST گمراه‌کننده است، `per_page=100` و اسلاگ‌ها در ۴ دسته داده شد:

1. `.../wp/v2/quantum_article?_fields=id,slug&per_page=100&slug=<47>` → ۴۵ مقالهٔ زنده (۲ موردِ باقی‌مانده برگه‌اند)
2. همان، دستهٔ دوم (۴۷) → ۴۶ زنده (۱ برگه)
3. همان، دستهٔ سوم (۴۷) → ۴۷ زنده
4. همان، دستهٔ چهارم (۴۴) → ۴۴ زنده
5. `.../wp/v2/pages?_fields=id,slug,status,link&per_page=100&slug=about-us,contact-us,privacy-policy` → هر سه `publish`

یادداشت: اسلاگ‌های `quantum-entanglement`، `google-willow-chip`، `quantum-photosynthesis`، `max-planck-blackbody`، `quantum-volume` **زنده نیستند** و عمداً استفاده نشدند (معادل‌های درست: `quantum-entanglement-explained`، `willow-chip`).

`nisq-era` (id 3307) که شما منتشر کردید، الان در صفحه لینک شده است.

## روش جایگذاری (دقیقاً همین صفحه)

1. پیش از هر چیز قالب را عوض کنید: **برگه‌ها → همهٔ برگه‌ها → «شروع» (id 3221) → ویرایش**؛ در ستون کناری، بخش **قالب (Template)** را از `page-homepage.php` روی **پیش‌فرض / Default** بگذارید، سپس «بروزرسانی».
   * دلیل: قالب `page-homepage.php` محتوای خودِ برگه را فقط در یک بخش ته‌ی صفحهٔ اصلی (`qp-page-content`) و با `wpautop` + `wp_kses_post` چاپ می‌کند. یعنی اگر قالب را عوض نکنید، متن **ناپدید نمی‌شود** ولی زیرِ هیرو و جدول دسته‌ها و «تازه‌ترین مقاله‌ها»ی صفحهٔ اصلی می‌آید و آنجا هر دو نسخهٔ صفحه دیده می‌شود. برای یک صفحهٔ تمیز، قالب پیش‌فرض درست است.
2. در همان ویرایشگر، اگر بلاک «HTML سفارشی» قبلی هست، روی آن کلیک کنید و در نوار ابزارِ بلاک روی «ویرایش به‌عنوان HTML» بزنید؛ همه را بگیرید و متنِ جدید را بچسبانید. اگر نیست: «افزودن بلاک» → **HTML سفارشی (Custom HTML)** → یک بلاک → کل فایل را داخل همان یک بلاک بچسبانید.
3. «بروزرسانی» → صفحهٔ `/start/` را با کشِ باز شده ببینید.

* داخل بلاک **فقط** HTML همین فایل باشد؛ نه `<style>`، نه `<script>`، نه `&` خام (فایل هیچ‌کدام را ندارد — چک شده).
* فایل داخل **یک** بلاک HTML سفارشی ساخته شده؛ بلاک‌بندی نکنید.
