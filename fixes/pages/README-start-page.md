# برگۀ «شروع اینجاست» (/start/)

## چرا چیدمان افتضاح بود (ریشۀ مشکل)

`GET /wp-json/wp/v2/pages?per_page=100` →

```json
{"id":3221,"slug":"start","title":"شروع اینجاست","template":"page-homepage.php"}
{"id":2790,"slug":"home",  "title":"کوانتوم پدیا فارسی","template":"page-homepage.php"}
```

برگۀ ۳۲۲۱ قالب **صفحۀ اصلی** را گرفته است. `page-homepage.php` (پوستۀ فرزند) کل صفحه را
با `WP_Query` می‌سازد و هرگز `the_content()` را صدا نمی‌کند ⇒ متنِ خودِ برگه هیچ‌وقت چاپ نمی‌شود
و به‌جایش «دسته‌بندی موضوعات» و «تازه‌ترین مقاله‌ها»ی صفحهٔ اصلی می‌آید. راه‌حل فقط یک کلیک است:
**ویرایشگر برگه ← ستون کنار (برگه) ← قالب ← «پیش‌فرض»** — و بعد چسباندن متنِ جدید.

## لینک‌های مرده در متن قبلی

۸۱ لینک در متن جدید، ۷۶ اسلاگِdistinct — همگی با
`/wp-json/wp/v2/quantum_article?per_page=100&slug=…` روی سایت زنده تأیید شده‌اند
(هیچ لینک ابداعی باقی نمانده). سه لینک پایین‌صفحه هم برگه‌های واقعی‌اند:
`/about-us/` (2261)، `/contact-us/` (2273)، `/privacy-policy/` (2308).

## متن جدید چه فرقی کرد

* لحن: «من اینجام تا…» حذف شد؛ راوی، «تیم کوانتوم‌پدیا» است (بدون شخصیت‌سازی خیالی).
* ادعاهای بدون پشتوانه و «۱۴۳» و «پادشاه آزمایش‌ها»گونه‌ها → جای خود را به معیارِ قابل‌آزمون داد:
  «هر ادعایی باید بگوید چه چیزی را پیش‌بینی می‌کند که فیزیک کلاسیک نمی‌تواند.»
* ساختار بر اساس دستورالعمل داخل سایت: `qp-intuition-box` برای پاسخ کوتاه، `qp-narrative-box`
  برای بخش پایانی، H2های کوتاه و پرسش‌های پرتکرار (4 پرسش، هر کدام ≤۶۰ کلمه).
* هر آیتم = لینک + یک خط «چرا این، اینجا» (معیارِ Google برای link context و_anchor text توصیفی_).
* مسیر پنجم اضافه شد: «وقتت کم است؟ این پنج مقاله» — برای کاربرِ کم‌وقت و برای featured snippet.
* بدون `<style>`، بدون `<script>`، بدون `<?php`، بدون `&` خام ⇒ در بلوک «HTML سفارشی» سالم می‌ماند.
* ۱۳۰۹ واژه؛ یک H1؛ H2ها برچسب‌های واقعیِ مسیرها.

## چسباندن

1. برگه ← «شروع اینجاست» ← ویرایش.
2. ستون کنار ← قالب ← **پیش‌فرض** (Default) ← ذخیره.
3. کل بلوک‌های داخل بدنه را حذف کن، یک بلوک **HTML سفارشی** اضافه کن و کل متن را در آن paste کن.
4. به‌روز‌رسانی. اگر کش فعال است: LiteSpeed Cache → Purge All.
5. انتخابی: تصویر شاخص ۱۶:۹ (از همان ۳۶ تصویر) + متن جانشین فارسی، و در افزونۀ سئو:
   * عنوان سئو (≤۶۰): `از کجا شروع کنیم؟ نقشۀ راه کوانتوم | کوانتوم‌پدیا`
   * توضیح متا (≤۱۵۵): `چهار مسیر یادگیری فیزیک کوانتوم در کوانتوم‌پدیا: الفبا، فناوری‌ها، تفسیرها و تاریخ؛ با لینک به مقالۀ مرتبط هر قدم.`
   * slug: `start` (بدون تغییر)
