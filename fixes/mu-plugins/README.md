# mu-plugins — دو فایل لازمِ QPedia

| فایل | چه می‌کند |
|---|---|
| `qpedia-pages-fix.php` (v2026.09.18-pages3) | برگه‌ها را از قاعدهٔ catch-all پوسته نجات می‌دهد: `/home/`، `/start/`، `/about-us/`، `/contact-us/`، `/privacy-policy/` و هر برگهٔ تازه. تأکید می‌کند این‌ها **بعنوان برگه** خوانده شوند. |
| `../fixes/home-recent-articles/qpedia-home-fix.min.php` | بخش «تازه‌ترین مقاله‌ها» را سمت سرور رندر می‌کند + آرشیو `/topics/` را می‌سازد + ابزار ترمیم تصویر شاخص. |

هر دو را در همان پوشه بگذار: `wp-content/mu-plugins/` (اسم فایل‌ها همین بماند؛ با هم تداخل ندارند — یکی `qpedia_pages_fix_*` و دیگری `qpedia_home_fix_*` / `qpedia_rows_v2` را استفاده می‌کند).

## نسخهٔ ۳ چه چیزی را نسبت به نسخهٔ قبلی (pages2) عوض کرد

۱. **`/start/` برگرندی اسلاگ داشت.** برگهٔ 3221 «شروع از اینجا» اسلاگ `start` گرفته، ولی مقالهٔ 2801 «شروع» هم همان اسلاگ را دارد؛ هر دو publish. قاعدهٔ catch-all پوسته برنده می‌شد ⇒ `/start/` مقاله را نشان می‌داد و برگه دیده نمی‌شد.
   در این نسخه فهرست «صفحه‌محور» اضافه شده: `start` و `home` **حتماً برگه**‌اند، حتی اگر مقاله‌ای همان اسلاگ را داشته باشد. اگر می‌خواهی `/start/` مالِ همان مقاله بماند، به‌جای force‌کردن، اسلاگِ یکی را عوض کن (پایین را ببین).

۲. **برگرندی‌ها را در پیشخوان اعلام می‌کند.** در داشبورد اطلاعیه‌ای می‌بینی که فهرست «اسلاگ مشترک برگه و مقاله» را نشان می‌دهد و یک دکمهٔ nonce‌دار دارد: «اسلاگ مقاله ← `start-2801`». تا روی آن کلیک نکنی، هیچ داده‌ای تغییر نمی‌کند.

۳. **مسیر برگه‌ها از `get_permalink()` خوانده می‌شود، نه از زنجیرهٔ پدر.** قبلاً اگر پدرِ یک برگه در زباله/پیش‌نویس می‌رفت، قاعدهٔ rewrite غلط ساخته می‌شد (مثلاً `privacy-policy` که پدرش 2275 منتشرشده نیست).

۴. **`/topics/` (آرشیو مقاله‌ها)** هم قاعده می‌گیرد تا catch-all بلعیدنی نباشد؛ اگر آن را منتشر نکردی، لینک «مشاهدهٔ همهٔ مقاله‌ها» همان‌جا ۴۰۴ می‌ماند.

۵. **جایگزین‌ها ۳۰۱ می‌شوند:** `/starting/` و `/start-here/` و `/begin/` ← `/start/`، `/about/` ← `/about-us/`، `/contact/` ← `/contact-us/`، `/privacy/` ← `/privacy-policy/`، `/front-page/` ← `/`. فهرست با فیلتر `qpedia_pages_fix_alias_map` قابل ویرایش است؛ اگر جای آن اسلاگ، برگهٔ منتشرشدهٔ دیگری باشد ریدایرکت انجام نمی‌شود.

۶. **`/home/` همان صفحهٔ اصلی را رندر می‌کند** (که خواستی نام صفحهٔ اول `home` باشد). canonicalِ خودِ وردپرس آن را به `/` ۳۰۱ می‌کند؛ این فایل جلوی آن را می‌گیرد. اگر رفتار استاندارد را می‌خواهی (یعنی `/home/` → `/`)، در انتهای همین فایل یا در mu-plugin دیگری بگذار:

```php
add_filter( 'qpedia_pages_fix_home_redirect', '__return_true' );
```

۷. اگر `page_on_front` تنظیم نشده باشد ولی برگهٔ `home` وجود داشته باشد، خودش وصل می‌کند (`show_on_front = page`).

## نصب با گوشی (cPanel)

1. cPanel → **File Manager** → مسیر `public_html/wp-content/mu-plugins`
2. اگر فایل `qpedia-pages-fix.php` هست: **راست‌کلیک → Replace/Upload** (نسخهٔ قبلی را نگه ندار؛ این نسخه جایش می‌آید). Backup می‌خواهی: اول **Rename** کن به `qpedia-pages-fix.php.old`.
3. اگر نیست: **+ File** → نام دقیق `qpedia-pages-fix.php` → **راست‌کلیک → Edit** → کل کد را بچسبان → **Save Changes**.
4. ابزارها → LiteSpeed Cache → **Purge All**.

نکته: ویرایشگر cPanel، ویرایشگر کد است؛ نقل‌قول‌ها خراب نمی‌شوند. ولی **این فایل را هرگز در محتوای برگه/بلوک HTML نچسبان** (فقط چاپ می‌شود).

## بعد از نصب، چه چیزی باید درست شود

| آدرس | قبل | بعد |
|---|---|---|
| `/home/` | ۴۰۴ (catch-all آن را «مقاله» می‌خواند) | صفحهٔ اصلی، همان `/` |
| `/start/` | مقالهٔ 2801 («شروع») | برگهٔ 3221 («شروع از اینجا») |
| `/starting/` | ۲۰۰ | ۳۰۱ به `/start/` |
| `/topics/` | ۴۰۴ | آرشیو مقاله‌ها |
| هر برگهٔ تازه‌ای که بعداً بسازی | ۴۰۴ تا دستی exception اضافه کنی | خودکار قاعده می‌گیرد |

اگر `/start/` هنوز مقاله را نشان داد: یعنی مقاله همان اسلاگ را نگه داشته و ترجیحش را داده‌ای — با دکمهٔ اطلاعیه، اسلاگ مقاله را به `start-2801` تغییر بده (آدرس مقاله عوض می‌شود؛ لینک‌های داخلی‌اش را مرور کن). راه دیگر: برگه را با اسلاگ دیگری بساز و `/start/` را به مقاله برگردان.

## فیلترهای در دسترس

```php
add_filter( 'qpedia_pages_fix_page_first_slugs', function ( $slugs ) {
	$slugs[] = 'shop';
	return $slugs;
} );

add_filter( 'qpedia_pages_fix_alias_map', function ( $map ) {
	$map['faq'] = 'about-us';
	unset( $map['begin'] );
	return $map;
} );

add_filter( 'qpedia_pages_fix_home_redirect', '__return_true' ); // /home/ → / (۳۰۱)
```

فیلترِ `page_first_slugs` تنها راه تعریف اسلاگ‌های صفحه‌محور است (گزینه‌ای در دیتابیس نمی‌نشیند، تا هیچ رفتارِ پنهانی در سایت نماند).

## بازگشت

`qpedia-pages-fix.php` را حذف (یا `.txt` کن) و یک‌بار Settings → Permalinks → Save Changes. تنها چیزی که این فایل عوض می‌کند «وضعیت انتشار» یک برگه و — فقط با کلیک خودت در پیشخوان — «اسلاگ» یک مقاله است. گزینهٔ `qpedia_pages_fix_version` هم در `wp-options` می‌ماند؛ بی‌ضرر است.
