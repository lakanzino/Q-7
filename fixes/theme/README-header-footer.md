# هدر و فوتر هم‌رنگ زمینۀ سایت

فایل منبع طراحی: `wp-content/themes/quantum-pedia-child/assets/css/custom.css`
(پوستۀ فرزند؛ `main.css` پوستۀ اصلی فقط استایل پیش‌فرض روشن را دارد و کاری به آن نداریم.)

در این فایل دو نوار تیره تعریف شده:

```
.qp-global-header { background-color:#0B3D91; … }
.qp-global-footer { background-color:#0B3D91; … }
```

و زمینۀ سایت:

```
body { background-color:#E8F6FF; grid: rgba(59,167,242,.07) 32px }
```

پس برای هم‌رنگ شدن، فقط باید همین رنگ + همان گرید به دو نوار داده شود و رنگ
متن‌های داخلشان (که برای زمینۀ تیره سفید نوشته شده) تیره شود — وگرنه نوشته‌ها نامرئی می‌شوند.

## اجرا (cPanel، موبایل)

1. File Manager → `public_html/wp-content/themes/quantum-pedia-child/assets/css/`
2. روی `custom.css` **راست‌کلیک → Download** (این نسخهٔ پشتیبان توست؛ فقط همین یک فایل).
3. همان‌جا راست‌کلیک → **Edit** (نه View) → در پنجرهٔ ویرایشگر به **انتهای کل فایل** برو (روی موبایل: انگشت را پایینِ کادر نگه‌دار تا اسکرول کند، یا `Ctrl+End` در میزکار).
4. کل بلوک `custom-append-header-footer.css` را همان‌جا **paste** کن.
5. **Save Changes** (ذیل پنجره، با تیک «Force Save» اگر پرسید).
6. از نوار ابزار بالای سایت: **LiteSpeed Cache → Purge All** (یا `?nocache=1` را به آدرس اضافه کن و رفریش کن).
7. اگر کادر تیرۀ تیترِ صفحه‌های دسته هم اذیت می‌کند، بلوک `custom-append-optional-dark-boxes.css` را هم زیر بلوک اول paste کن.

⚠️ **این را در برگه، بلوک «HTML سفارشی»، یا ویرایشگر مقاله کپی نکن.** این CSS است و جای آن فقط داخل فایل `custom.css` است.

## بازگشت

راست‌کلیک → Edit روی `custom.css` → از خط `/* ═══ هدر و فوتر — هم‌رنگ زمینۀ سایت` تا آخر فایل را پاک کن و Save بزن. یا فایل دانلودشده در مرحله ۲ را همان‌جا Replace/Rename بگذار.

## چرا `!important`

قاعده‌های خودِ `custom.css` (بخش «فوتر باریک» که بعد از بخش اول می‌آید) همان
گزیننده‌ها را دوباره تعریف می‌کنند؛ بلوک ما آخر فایل است، ولی برای اینکه کش LiteSpeed
یا هر استایل تزریقیِ دیگر ترتیب را عوض نکند، روی رنگ‌ها `!important` گذاشته شده.
سایه‌ها و padding عمداً دست‌نخورده ماندند تا ارتفاع و چیدمان تغییر نکند.

## چیزی که عوض **نمی‌شود**

- خطِ امضای سه‌رنگ (آبی → فیروزه‌ای → نارنجی) بالای فوتر و زیر هدر: تنها جداکنندۀ باقی‌مانده است، نگه داشته شد.
- رنگ دکمنۀ جست‌وجو (`#F4A261`) و برچسب‌ها: طبق بند ۱.۵ پالت Ocean Breeze.
- کارت‌های مقاله و بخش‌های صفحهٔ اول.
