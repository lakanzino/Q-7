# صفحه اصلی Qpedia

فایل `home.html` نسخه کامل و مستقل صفحه اصلی است.

## استفاده در وردپرس

اگر قالب یا ویرایشگر، سند کامل HTML را می‌پذیرد، محتوای فایل را کامل وارد کنید. اگر بلوک «HTML سفارشی» فقط محتوای داخل صفحه را می‌پذیرد:

1. محتوای تگ `<style>` را در CSS سفارشی قالب قرار دهید.
2. فقط محتوای داخل `<main class="q-home">...</main>` را در صفحه Home قرار دهید.
3. صفحه را بدون سایدبار و با عرض کامل تنظیم کنید.

## لینک‌هایی که باید با آدرس واقعی سایت تطبیق داده شوند

- `/از-کجا-شروع-کنیم/`
- `/articles/`
- مسیر دسته‌بندی‌ها در شش کارت موضوعی
- لینک سه مقاله منتخب

صفحه فاقد کتابخانه خارجی، فونت خارجی، JavaScript و تصویر سنگین است. انیمیشن‌ها با CSS و SVG داخلی اجرا می‌شوند و حالت `prefers-reduced-motion` رعایت شده است.
