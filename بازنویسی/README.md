## نحوهٔ اعمال در ووردپرس (برای هر مقاله)

1. **عنوان اصلی** ← فیلد عنوان (اسلاگ/URL **بدون تغییر** بماند)
2. **عنوان SEO / توضیحات متا / کلیدواژه اصلی** ← فیلدهای `_qpedia_seo_title`، `_qpedia_meta_description`، `_qpedia_focus_keyphrase` (فیلدهای رنک‌مات/یوست را خالی بگذارید)
3. **متن مقاله** ← جایگزینی کاملِ محتوای فعلی (بخش‌ها: مقدمه، پاسخ کوتاه، این مفهوم چیست، قدم‌به‌قدم، مثال، کجا به کار می‌آید، سوءبرداشت‌ها، چه نمی‌دانیم، مرتبط، جمع‌بندی، منابع، FAQ)
4. **بلوک «مقاله‌های مرتبط» قالبی قدیمی** (مایورانا/تاریخ/بورن) ← حذف و جایگزینی با ۳ لینک اختصاصیِ همین فایل
5. **ALT تصویر شاخص** ← طبق هر فایل (observer و quantum-state خالی‌اند؛ wave-function تصویرش را عوض کنید)
6. دسته/برچسب‌ها ← طبق «اطلاعات اولیه» هر فایل (قائم‌اند؛ تغییر در اسلاگ دسته‌ها لازم نیست)

## موارد باز (در انتظار شما)
