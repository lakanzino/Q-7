# ممیزی کامل سئو و ساختار مقالات qpedia.ir — راهنمای بستهٔ گزارش

همهٔ گزارش‌ها از **فایل‌های خام خروجی سایت** (`WordPress.2026-09-20.xml` و دو فایل همراه، به‌علاوهٔ قالب فرزند) تولید شده‌اند؛ **بدون هیچ آمار حدسی**. بازتولید:

```bash
python3 seo-audit/tools/qp_audit.py "/path/to/Q-7"    # استخراج داده + امتیاز + ایراد
python3 seo-audit/tools/qp_reports.py "/path/to/Q-7"  # ساخت گزارش‌ها و نمودارها
python3 seo-audit/tools/qp_fixdata.py "/path/to/Q-7"  # دادهٔ آمادهٔ افزونه + قوانین ریدایرکت
```
