# افزونهٔ یک‌بارمصرف «QP One-Off Fixes» — راهنمای استفاده

افزونه‌ای اختصاصی برای اجرای **مرحله‌به‌مرحله و قابل‌بازگشتِ** اصلاحاتی که در ممیزی سایت (پوشهٔ `seo-audit`) استخراج شد. دادهٔ اصلاحات از خودِ خروجی واقعی سایت تولید شده است؛ هیچ محتوایی «حدس» زده نشده.

## نصب
1. فایل `qp-one-off-fixes.zip` را در پیشخوان وردپرس: افزونه‌ها → افزودن → بارگذاری افزونه → نصب و فعال‌سازی.
2. از منوی **ابزارها → QP یک‌بارمصرف‌ها** صفحهٔ ابزار را باز کنید.

## ایمنی
- قبل از هر اعمال، مقدار قبلی در جدول `wp_qpof_backup` ذخیره می‌شود و دکمهٔ «بازگردانی» همان بخش همه‌چیز را برمی‌گرداند.
- افزونه هیچ پستی را حذف نمی‌کند، وضعیت را تغییر نمی‌دهد و فقط روی محتوای منتشرشده کار می‌کند.
- بعد از اتمام کار، افزونه را غیرفعال و حذف کنید. اگر می‌خواهید ریدایرکت‌ها مستقل از افزونه بمانند، محتویات `seo-audit/redirects/htaccess-301-rules.txt` را در `.htaccess` ریشهٔ هاست (بالای بلوک وردپرس) کپی کنید یا CSV کنار آن را در افزونهٔ Redirection ایمپورت کنید.

## محدودیت‌ها و نکات
- جایگزینی لینک با تطابق رشته‌ای دقیق `href="…"` انجام می‌شود؛ اگر محتوای سایت بعد از تاریخ خروجی (۲۰ سپتامبر) دست‌کاری شده باشد، ممکن است چند مورد «پیدا نشد» گزارش شود — طبیعی است و خطری ندارد.
- پیش‌نویس‌ها (۱۰۳ مقاله) دست‌نخورده می‌مانند؛ بعد از انتشار هر کدام، خروجی تازه بگیرید و ابزار را به‌همان شکل به‌روزرسانی کنید (`qp_fixdata.py`).
- متا/کلیدواژه‌های پرشده «پیش‌پر» هستند، نه جایگزین نگاه انسانی؛ اما از متن واقعی خودِ مقاله گرفته شده‌اند.
