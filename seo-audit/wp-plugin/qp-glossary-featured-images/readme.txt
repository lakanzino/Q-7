۵۵ تصویر شاخص تازه را جای تصویر قبلی مقاله‌ها می‌گذارد و تصویر قبلی را حذف می‌کند.

== مشخصات تصاویر ==

* نسبت تصویر: ۱۶:۹ (۱۲۰۰×۶۷۵)
* قالب: WebP با کیفیت ۸۲
* حجم میانگین: ۳۳ کیلوبایت (کل مجموعه ۱٫۷ مگابایت)
* نام فایل: اسلاگ انگلیسی همان مقاله (مثل wave-particle-duality.webp)

== نصب و اجرا ==

۱. افزونه‌ها ← افزودن ← بارگذاری افزونه ← انتخاب زیپ ← نصب ← فعال‌سازی
۲. «ابزارها ← تصاویر شاخص جدید»
۳. اول «فقط بررسی (بدون تغییر)» را بزنید.
۴. بعد «اجرای همه (۵۵ مقاله)».

== رفتار افزونه ==

| حالت | تعداد | کار |
|---|---|---|
| نام فایل یکسان | ۴۰ | فایل سرجایش بازنویسی می‌شود؛ آدرس تصویر عوض نمی‌شود |
| نام فایل متفاوت | ۱۲ | تصویر تازه با نام اسلاگ ساخته می‌شود و تصویر قبلی حذف می‌گردد |
| بدون تصویر شاخص | ۳ | تصویر تازه اضافه می‌شود |

* تصویر قبلی که با مقالهٔ دیگری مشترک است، حذف نمی‌شود (در گزارش مشخص می‌شود).
* متن جانشین (alt) فارسی و نام انگلیسی تصویر ثبت می‌شود.
* گزینهٔ پیش‌فرض: نسخهٔ پشتیبان تصویر قبلی در `wp-content/uploads/qp-fi-backup/` نگه داشته می‌شود.
  اگر حذف کامل می‌خواهید، تیک آن را بردارید.

== نکتهٔ سئو ==

WebP + نسبت ۱۶:۹ + نام اسلاگ انگلیسی + alt فارسی، هم برای سرعت (LCP) و هم برای
جست‌وجوی تصویری گوگل بهتر از تصاویر قبلی است.
