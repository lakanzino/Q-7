== متن جانشین (alt) — استاندارد گوگل ==

برای هر ۵۵ تصویر یک alt اختصاصی نوشته شده که:

* تصویر را توصیف می‌کند (نه انباشت کلیدواژه)
* **کلمهٔ کلیدی کانونی همان مقاله** را در خود دارد (استخراج‌شده از `rank_math_focus_keyword`)
* زیر ۱۲۵ نویسه است (توصیهٔ گوگل)
* عبارت‌های بی‌ارزش مثل «تصویر از» ندارد

نمونه:

| مقاله | کلمهٔ کلیدی | متن جانشین |
|---|---|---|
| wave-particle-duality | دوگانگی موج و ذره | دوگانگی موج و ذره؛ یک الکترون با دو رفتار موجی و ذره‌ای |
| quantum-tunneling | تونل‌زنی کوانتومی | تونل‌زنی کوانتومی؛ عبور ذره از سدی که در فیزیک کلاسیک ناممکن است |
| decoherence | واهمدوسی | واهمدوسی؛ از دست رفتن همدوسی و پخش اطلاعات فاز در محیط |
| planck-constant | ثابت پلانک | ثابت پلانک؛ کوچک‌ترین بستهٔ انرژی و نقطهٔ آغاز فیزیک کوانتومی |

در کتابخانهٔ رسانه ذخیره می‌شود:
`_wp_attachment_image_alt` (متن جانشین) · `_qpfi_kw` (کلمهٔ کلیدی) · `_qpfi_en` (نام انگلیسی)

== نصب و اجرا ==

۱. افزونه‌ها ← افزودن ← بارگذاری افزونه ← نصب ← فعال‌سازی
۲. «ابزارها ← تصاویر شاخص جدید»
۳. اول «فقط بررسی (بدون تغییر)» — پیش‌نمایش تصویر فعلی/تازه و متن alt هر مقاله.
۴. «اجرای همه (۵۵ مقاله)».

== رفتار ==

| حالت | تعداد | کار |
|---|---|---|
| نام فایل یکسان | ۴۰ | فایل سرجایش بازنویسی می‌شود؛ آدرس تصویر عوض نمی‌شود |
| نام فایل متفاوت | ۱۲ | تصویر تازه ساخته می‌شود و تصویر قبلی حذف می‌گردد |
| بدون تصویر شاخص | ۳ | تصویر اضافه می‌شود |

* تصویر قبلی که با مقالهٔ دیگری مشترک است حذف نمی‌شود (در گزارش مشخص می‌شود).
* پشتیبان اختیاری تصویر قبلی در `wp-content/uploads/qp-fi-backup/`.
* اجرای دوباره بی‌خطر و بدون ساخت تصویر تکراری است.
