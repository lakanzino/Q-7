# چکیده اصلی مخزن freebuff

- **مخزن:** `lakanzino/freebuff`
- **موضوع اصلی:** عامل کدنویسی آزاد مبتنی بر Codebuff
- **شاخه بررسی‌شده:** `main`
- **فایل‌های SKILL.md:** یک فایل نمونه

Freebuff یک برنامه عامل کدنویسی است، نه کاتالوگ مهارت‌های آماده برای بازنویسی مقاله. تنها فایل `SKILL.md` آن یک قالب نمونه برای نمایش ساختار مهارت است و به‌عنوان مهارت محتوایی مستقل نباید فعال شود.
