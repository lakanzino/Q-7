# چکیده اصلی مخزن agentic-awesome-skills

- **مخزن:** `lakanzino/agentic-awesome-skills`
- **موضوع اصلی:** کاتالوگ و کنترل‌پلین محلی برای کشف، انتخاب، اعتبارسنجی و برنامه‌ریزی مجموعه‌های مهارتی عامل‌ها
- **شاخه بررسی‌شده:** `main`
- **رکوردهای کاتالوگ رسمی `skills_index.json`:** ۲٬۱۴۱
- **فایل‌های دارای نام `SKILL.md` در کل درخت مخزن:** ۶٬۷۳۰

تفاوت دو عدد بالا واقعی است: شمارش فایل‌ها نسخه‌های افزونه‌ای، کپی‌ها یا مسیرهای جانبی را هم در بر می‌گیرد؛ برای موجودی اصلی از کاتالوگ رسمی ۲٬۱۴۱ رکوردی استفاده شده است.

این مخزن فقط مجموعه مهارت‌های نوشتاری نیست. مهارت‌های امنیتی، توسعه، زیرساخت، عامل‌ها، بازاریابی، محتوا، اتوماسیون و ابزارهای عملیاتی را نیز شامل می‌شود. بنابراین فعال‌سازی کورکورانه همه مهارت‌ها برای بازنویسی مقاله درست یا ایمن نیست. ستون `risk` باید پیش از انتخاب بررسی شود.
