# چکیده اصلی مخزن blog-translation-agent

- **مخزن:** `lakanzino/blog-translation-agent`
- **موضوع اصلی:** خط لوله ترجمه مقاله‌های وبلاگی فنی با حفظ ساختار Markdown
- **شاخه بررسی‌شده:** `main`
- **فایل‌های SKILL.md:** صفر

این مخزن یک ابزار/عامل ترجمه است و در قالب استاندارد `SKILL.md` مهارتی ارائه نمی‌کند. براساس README، برای واکشی مقاله، ترجمه، پردازش تصویر، اعتبارسنجی محتوا و انتشار Pull Request طراحی شده و از چند دامنه و زبان پشتیبانی می‌کند. بنابراین باید به‌عنوان ابزار ترجمه جداگانه استفاده شود، نه مهارتی که خودکار برای بازنویسی فارسی فعال شود.

## نتیجه بررسی

هیچ فایل مهارت استانداردی برای کپی یا نصب پیدا نشد. برای استفاده از قابلیت‌های آن باید دستورالعمل اجرایی و متغیرهای محیطی خود مخزن بررسی شوند.
