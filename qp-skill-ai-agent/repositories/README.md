# مخزن چکیده مجموعه‌های مهارتی

این بخش نتیجه بررسی واقعی مخزن‌هایی است که در حساب GitHub کاربر دیده شدند.

| مخزن | نوع | نتیجه بررسی | فایل |
|---|---|---|---|
| `skills` | مجموعه مهارت‌های UiPath | ۲۷ مهارت اصلی؛ ۴۱ فایل SKILL با احتساب نسخه‌های جانبی | [چکیده](./skills/SUMMARY.md) |
| `freebuff` | عامل کدنویسی | یک SKILL نمونه؛ کاتالوگ محتوایی نیست | [چکیده](./freebuff/SUMMARY.md) |
| `blog-translation-agent` | ابزار ترجمه وبلاگ | فاقد فایل SKILL.md | [چکیده](./blog-translation-agent/SUMMARY.md) |
| `agentic-awesome-skills` | کاتالوگ و کنترل‌پلین مهارت | ۲٬۱۴۱ رکورد رسمی؛ ۶٬۷۳۰ فایل SKILL در کل درخت | [چکیده](./agentic-awesome-skills/SUMMARY.md) |
| `agent-skills` | مهارت‌های تخصصی WordPress | ۱۸ مهارت | [چکیده](./agent-skills/SUMMARY.md) |

## موجودی‌های کامل

فایل‌های `skills-inventory.csv` نام، توضیح اصلی، مسیر و در صورت وجود دسته و سطح ریسک را ثبت می‌کنند. توضیحات این موجودی‌ها از داده واقعی مخزن‌ها استخراج شده‌اند و ترجمه یا حدس ماشینی جایگزین آن‌ها نشده است.

## استفاده برای بازنویسی مقاله

فرمان استاندارد در [`../ARTICLE-REWRITE-COMMAND.md`](../ARTICLE-REWRITE-COMMAND.md) قرار دارد. همه مهارت‌ها نباید هم‌زمان فعال شوند؛ ابتدا همه فهرست‌ها بررسی و سپس فقط مهارت‌های مرتبط و کم‌خطر انتخاب می‌شوند.
