# قانون دائمی آرشیو مهارت‌های Qpedia

از این پس، برای هر مخزن مهارت که فورک، دریافت یا نصب می‌شود، مراحل زیر الزامی است:

1. مخزن و فایل‌های آن پیش از استفاده بررسی شوند.
2. نام مخزن اصلی، مالک، نشانی منبع و تاریخ دریافت ثبت شود.
3. فایل اصلی مهارت بدون حذف قواعد مؤثر، برای زبان فارسی بومی‌سازی شود.
4. قواعد ویژه زبان فارسی فقط براساس نیاز واقعی و با توضیح روشن افزوده شوند.
5. نسخه کامل فارسی در `qp-skill-ai-agent/<skill-name>/SKILL.md` ذخیره شود.
6. چکیده کاربرد، محدودیت‌ها، روش فراخوانی و تغییرات فارسی در `SUMMARY.md` نوشته شود.
7. اطلاعات منبع و نسخه در `SOURCE.md` ثبت شود.
8. فایل‌های کمکی لازم مانند ارزیابی یا تنظیمات عامل در همان زیرپوشه نگهداری شوند.
9. مهارت نصب‌شده با نسخه آرشیوشده مقایسه و در صورت امکان با هش کنترل شود.
10. فقط پس از بررسی، فایل‌ها روی شاخه فعال GitHub قرار گیرند و لینک GitHub ارائه شود.
11. هیچ قابلیت، نتیجه نصب یا موفقیت push بدون آزمون واقعی گزارش نشود.
12. اگر مجوز، داده یا قطعیت کافی وجود ندارد، وضعیت دقیق و صریح گزارش شود و چیزی حدس زده نشود.

## قرارداد نام‌گذاری

- نام پوشه با نام رسمی مهارت و با حروف کوچک نوشته شود.
- فایل اصلی همواره `SKILL.md` باشد.
- چکیده همواره `SUMMARY.md` باشد.
- اطلاعات منبع همواره `SOURCE.md` باشد.
- فایل‌های جانبی نام اصلی خود را حفظ کنند، مگر اینکه برخورد نام ایجاد شود.

## دامنه اجرا

این قانون برای همه مهارت‌های آینده Qpedia اجرا می‌شود؛ چه مهارت از GitHub فورک شده باشد، چه از مخزن دیگری دریافت شده باشد و چه ابتدا به‌صورت محلی نصب شود.
