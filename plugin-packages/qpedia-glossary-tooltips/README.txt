Qpedia Glossary Tooltips 1.0.0

نصب:
1. فایل ZIP را در افزونه‌ها ← افزودن بارگذاری و فعال کنید.
2. از منوی «اصطلاحات» تعریف‌ها را ویرایش یا اصطلاح تازه اضافه کنید.
3. عنوان نوشته، عبارت اصلی اصطلاح است؛ چکیده تعریف کوتاه تولتیپ است؛ متن کامل صفحه اختصاصی اصطلاح را می‌سازد.
4. صورت‌های جایگزین را در باکس کناری، هر مورد در یک خط ثبت کنید.

رفتار:
- فقط داخل نوشته‌های quantum_article فعال است.
- حداکثر ۱۲ اصطلاح یکتا را در هر مقاله و فقط نخستین رخداد هر اصطلاح هایلایت می‌کند.
- داخل لینک، دکمه، کد، تیتر، script و style دست نمی‌برد.
- با کلیک، لمس، Enter و Space کار می‌کند و با Escape یا لمس بیرون بسته می‌شود.
- باکس بر اساس فضای صفحه بالا یا پایین اصطلاح باز می‌شود و در عرض موبایل از صفحه بیرون نمی‌زند.
- فعال‌سازی نخست ۱۵ تعریف پایه و قابل‌ویرایش می‌سازد.
- حذف افزونه، اصطلاحات ساخته‌شده را حذف نمی‌کند.

کنترل کیفیت:
- نوشته تازه از نوع quantum_article ساخته نمی‌شود.
- محتوای ذخیره‌شده مقاله تغییر نمی‌کند؛ هایلایت فقط هنگام نمایش اعمال می‌شود.
- CSS و JavaScript فقط در صفحه مقاله بارگذاری می‌شوند.
