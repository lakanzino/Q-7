Qpedia One-Time Importer 001–025
================================
این افزونه مقاله‌های موجود ۱ تا ۲۵ را با ID یا نامک پیدا و به‌روزرسانی می‌کند.
عنوان، HTML، عنوان SEO، توضیحات متا، کلمه کلیدی Rank Math و FAQ Schema ثبت می‌شوند.
وضعیت، تاریخ، نویسنده و تصویر شاخص تغییر نمی‌کنند و مقاله تکراری ساخته نمی‌شود.
روش: پشتیبان پایگاه داده ← نصب ZIP ← فعال‌سازی ← ابزارها ← درون‌ریز Qpedia 001–025 ← اجرای یک‌باره ← بررسی و حذف افزونه.

تاریخ انتشار اصلی، نویسنده، وضعیت و تصویر شاخص حفظ می‌شوند. WordPress هنگام اجرای واقعی، post_modified را به‌طور طبیعی به‌روزرسانی می‌کند.
