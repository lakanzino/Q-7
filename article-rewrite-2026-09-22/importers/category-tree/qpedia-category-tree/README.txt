Qpedia Category Tree Installer — نسخه 1.1

کارکرد:
1. حذف کامل تمام دسته‌های قبلی taxonomy با نام quantum_category
2. حذف اتصال دسته‌های قدیمی از مقاله‌ها (بدون حذف یا ویرایش خود مقاله)
3. ایجاد ساختار پاک نهایی شامل ۴ دسته مادر و ۱۲ دسته عمومی
4. تنظیم رابطه صحیح مادر/فرزند بر اساس ساختار نهایی ۱۸۴ مقاله

مواردی که تغییر نمی‌کنند:
- هیچ مقاله‌ای ساخته یا حذف نمی‌شود.
- عنوان، متن، تاریخ، نویسنده، وضعیت و تصویر مقاله‌ها تغییر نمی‌کند.
- permalink مقاله‌ها تغییر نمی‌کند و نشانی مقاله همچنان /postname/ می‌ماند.
- rewrite rules تغییر نمی‌کنند.

نکته مهم:
پس از پاک‌سازی، مقاله‌های قبلی بدون دسته می‌شوند. طبق تصمیم شما، آن مقاله‌ها باید دستی در دسته‌های جدید قرار گیرند. درون‌ریزهای مقاله‌های بعدی نیز دسته نهایی هر مقاله را خودکار ثبت می‌کنند.

روش اجرا:
1. فایل ZIP را در افزونه‌ها ← افزودن بارگذاری و فعال کنید.
2. از پایگاه داده نسخه پشتیبان بگیرید.
3. به ابزارها ← ساخت دسته‌بندی Qpedia بروید.
4. دکمه «حذف دسته‌های قبلی و ساخت ۱۶ دسته نهایی» را بزنید.
5. پس از پیام موفقیت، افزونه را غیرفعال و حذف کنید.

این نسخه option مستقل v2 دارد؛ حتی اگر نسخه قبلی اجرا شده باشد، نسخه پاک‌سازی یک بار قابل اجرا است.
