# Qpedia Public Scope Cleanup

- حذف دائمی کنترل‌شده: 118 مقاله
- ریدایرکت 301: 55 URL ادغامی/تکراری
- پاسخ 410: 63 URL تخصصی حذف‌شده
- مقالات بخش دانشمندان: 8 مورد، دست‌نخورده

## اجرا
1. پیش از هر کار از پایگاه داده پشتیبان بگیرید.
2. ZIP را در افزونه‌های وردپرس نصب و فعال کنید.
3. به ابزارها ← Qpedia Cleanup بروید.
4. عبارت `DELETE 118` را وارد و حذف دسته بعدی را اجرا کنید. هر اجرا حداکثر 20 مورد را حذف می‌کند.
5. تا تکمیل 118 مورد ادامه دهید.
6. افزونه را فعال نگه دارید؛ ریدایرکت‌های 301 و پاسخ‌های 410 به آن وابسته‌اند.

افزونه پیش از حذف، Post ID، post type و slug را هم‌زمان تطبیق می‌دهد. مورد ناسازگار حذف نمی‌شود و در صفحه مدیریت گزارش می‌شود.
