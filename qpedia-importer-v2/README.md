# Qpedia Importer 2 (موقت — دستهٔ دوم)

به‌روزرسانی ۵ مقالهٔ دوم + ۵ دیاگرام آموزشی + اصلاح ALT تصویر شاخص.
**بعد از اجرای موفق، افزونه را غیرفعال و حذف کنید.**

## مقاله‌ها
| اسلاگ | دیاگرام |
|---|---|
| quantum-superposition | جمع برداریِ دو جزء برهم‌نهی |
| quantum-entanglement-explained | جفت درهم‌تنیده بدون سیم و سیگنال |
| double-slit-experiment | چیدمان آزمایش: چشمه، دو شکاف، الگوی تداخل |
| quantum-tunneling | موج + سد + دُمِ آن‌سوی سد |
| quantum-measurement | فروپاشی از موج پهن به قلهٔ تیز |

## تفاوت با نسخهٔ ۱
- **تصویر شاخصِ فعلی دست نمی‌خورد** — فقط ALT (متن جایگزین) اش اصلاح می‌شود.
- پیشوند‌ها و گزینه‌ها جدا (`qpedia_imp2_*`) — می‌تواند هم‌زمان با نسخهٔ ۱ فعال باشد.

## نصب و اجرا
1. WP Admin → Plugins → Add New → Upload Plugin → `qpedia-importer-v2.zip`
2. فعال کنید → منوی «Qpedia Importer 2» → «اجرای به‌روزرسانی»
3. در گزارش هر ۵ خط باید ✅ باشد.
4. نمونه‌چک یک مقاله: متن، دیاگرام با کپشن هایلایت آبی، ALT تصویر شاخص در ویرایشگر.
5. افزونه را غیرفعال و حذف کنید.

## اگر چیزی خطا داد
به‌جای پاک‌کردن سایت، لینک افزونه را بفرستید تا دیباگ کنم.
