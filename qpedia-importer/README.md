# Qpedia Importer (نسخهٔ ۲.۰ — ۱۰ مقاله در یک افزونه، موقت)

این نسخه جایگزینِ v1 و v2 است. ۱۰ مقالهٔ بازنویسی‌شده + ۱۸ تصویر را یک‌جا به‌روزرسانی می‌کند.
**بعد از اجرای موفق، افزونه را غیرفعال و حذف کنید.**

## چرا نسخهٔ قبل خطای نصب داد؟
در کدِ v1 یک خطاِ دست‌وپنجهٔ تایپی (متنِ فارسی بدون‌ گیومه) باعث **Parse Error** در فایلِ افزونه شده بود؛
WordPress چنین فایلی را «خراب» تشخیص می‌دهد و نصب/فعال‌سازی‌اش با خطا تمام می‌شود.
نسخهٔ ۲.۰ با آنالیز استاتیکِ PHP + dry-run موتورِ ایمپورت تست شده است.

## چه کار می‌کند؟
| دسته | مقاله‌ها | تصویر شاخص |
|---|---|---|
| اول | qubit, decoherence, observer, quantum-state, wave-function | ۵ تصویرِ شاخصِ **جدید** آپلود و تنظیم می‌شود |
| دوم | quantum-superposition, quantum-entanglement-explained, double-slit-experiment, quantum-tunneling, quantum-measurement | تصویر شاخصِ فعلی **می‌ماند**؛ فقط ALT اصلاح می‌شود |

برای هر دو دسته: عنوان، متن، فیلدهای `_qpedia_*`، دسته و برچسب، و ۱۳ دیاگرام آموزشی
(با کپشنِ هایلایتِ آبی زیر هر تصویر). URL مقالات تغییر نمی‌کند؛ فقط آپدیت می‌شود،
مقالهٔ جدید ساخته نمی‌شود.

## نصب و اجرا
1. اگر در فهرستِ افزونه‌ها entryِ قدیمیِ «Qpedia Importer» (خراب) می‌بینید، **اول حذفش کنید**
   (یا پوشهٔ `wp-content/plugins/qpedia-importer` را از FTP پاک کنید).
2. WP Admin → Plugins → Add New → Upload Plugin → `qpedia-importer.zip`
3. فعال کنید → منوی «Qpedia Importer» → «اجرای به‌روزرسانی»
4. در گزارش باید **۱۰ خط با ✅** ببینید (بدون هیچ «خطا:»).
5. نمونه‌چک یک مقاله از هر دسته: متن، دیاگرام + کپشنِ آبی، تصویر شاخص و ALT آن.
6. افزونه را غیرفعال و حذف کنید.

## تکرارپذیری
اجرا idempotent است؛ اگر لازم شد دوباره بزنید (تصاویرِ تکراری آپلود نمی‌شود).
