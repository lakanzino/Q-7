# Qpedia Importer (افزونهٔ موقت)

افزونهٔ یک‌بارمصرف برای اعمال ۵ مقالهٔ بازنویسی‌شده + ۱۳ تصویر (webp سبک) روی سایت.
بعد از اجرای موفق، **غیرفعال و حذف** کنید.

## پوشه‌بندی

```
qpedia-importer/
├── qpedia-importer.php      ← افزونه (این فایل اصلی است)
├── images-map.php           ← ALT و کپشن (هایلایت آبی) هر تصویر
├── content/                 ← محتوای ۵ مقاله (JSON: عنوان، متا، متن HTML)
│   ├── qubit.json
│   ├── decoherence.json
│   ├── observer.json
│   ├── quantum-state.json
│   └── wave-function.json
└── assets/images/           ← ۱۳ تصویر webp (۵ شاخص + ۸ آموزشی)
```

## نصب و اجرا (۵ دقیقه)

1. در `wp-admin` → **افزونه‌ها ← افزودن ← بارگذاری افزونه** → فایل `qpedia-importer-v1.zip` را آپلود و فعال کنید.
2. منوی «**Qpedia Importer**» در نوار کناری ظاهر می‌شود → روی **«اجرای به‌روزرسانی»** بزنید.
3. گزارش را چک کنید: باید ۵ خط ✅ ببینید (هر مقاله + تعداد تصاویر).
4. سایت را ببینید: ۵ مقاله + تصاویر با کپشن هایلایت آبی.
5. افزونه را **غیرفعال و حذف** کنید (از همان منوی افزودن افزونه‌ها).

## چه چیزی را تغییر می‌دهد (و چه چیزی را نه)

| تغییر | نه |
|---|---|
| عنوان مقاله (اسلاگ/URL **ثابت** می‌ماند) | پست جدید ساخته نمی‌شود |
| متن کامل مقاله | پست‌های دیگر دست‌نخورده |
| `_qpedia_seo_title` / `_qpedia_meta_description` / `_qpedia_focus_keyphrase` | دسته‌های دیگر |
| دسته‌ها (quantum_category) و برچسب‌ها | فیلدهای rank_math/yoast (دست نمی‌خورند) |
| تصویر شاخص + ۸ تصویر آموزشی با کپشن آبی | |
| بلوک «مقاله‌های مرتبط» قالبی → ۳ لینک اختصاصی (داخل متن) | |

## نکات

- **idempotent است**: اگر دوباره اجرا کنید، دوباره مقاله را آپدیت می‌کند و تصاویر تکراری آپلود نمی‌شود (mapping در option `qpedia_importer_attachments` نگهداری می‌شود).
- اگر بعداً می‌خواهید افزونه را پاک کنید و mapping باقی مانده را هم پاک کنید: در Query Monitor/PHPMyAdmin option با نام `qpedia_importer_attachments` و transient `qpedia_importer_report` را حذف کنید (اختیاری؛ چند کیلوبایت است).
- بعد از اجرا، یک‌بار **Purge All** در LiteSpeed Cache بزنید.
- تصاویر در کتابخانهٔ رسانه زیر `wp-content/uploads/YYYY/MM/` می‌مانند (پس از حذف افزونه هم پابرجا).

همهٔ تصاویر داخل `assets/images/` — ۱۳ فایل webp (مجموع ~۳۴۰KB).
